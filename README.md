## Prerequisites

Pastikan environment pengembangan Anda memenuhi spesifikasi berikut sebelum menjalankan proyek (referensi: [React Native Environment Setup](https://reactnative.dev/docs/set-up-your-environment)):

- **Node.js** (`>= 20.x`) dan package manager (`npm`, `yarn`, atau `pnpm`)
- **JDK 17** dan **Android Studio** (Android SDK serta Android Virtual Device) untuk target Android
- **Xcode** dan **CocoaPods** (khusus macOS) untuk target iOS
